Developed a web-based Employee Attendance Management System using FastAPI, SQLite3, HTML, CSS, and Jinja2 Templates. 
The system enables secure employee login, check-in/check-out functionality, attendance tracking, attendance history management, 
and report generation. An admin dashboard allows employee management, attendance monitoring, and exporting attendance records to 
Excel and PDF formats. The application features role-based access control, session management, and a responsive user interface for 
efficient attendance tracking and workforce management.
